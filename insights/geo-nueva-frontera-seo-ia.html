GEO: cómo aparecer en las respuestas de la IA

Hipótesis

Los asistentes de IA no ven tu web como la ves tú. Descargan el HTML que sirve el servidor y no ejecutan JavaScript. Si tus servicios, tus datos de empresa o tus contenidos solo existen después de que el navegador ejecute un script, para ellos tu web está vacía.

Y lo que no ven, no lo citan. Esta es la hipótesis, cómo se comprueba y lo que encontramos al medirla en sitios reales.

El método: no hay que adivinar

Para saber qué ve un rastreador no hace falta especular. Se pide la página sin navegador y se compara con lo que ve un visitante. Diez segundos: 

curl -s https://tusitio.cl/ | grep -c "@type"

Si eso devuelve 0 y al inspeccionar la misma página con el navegador ves datos estructurados, acabas de encontrar el problema: existen, pero solo para quien ejecuta JavaScript.

Los rastreadores de los asistentes —GPTBot, ClaudeBot, PerplexityBot— descargan el HTML. La renderización con JavaScript es territorio de los buscadores. De ahí sale la trampa: el mismo sitio puede estar perfecto en Google y ser invisible para una IA.

Lo que encontramos al medirlo

Tres casos reales, medidos en septiembre de 2026 con este mismo método.

Caso 1: la ficha que solo existía con JavaScript. Una consultora de servicios profesionales, 13 páginas. En el HTML servido: cero bloques de datos estructurados. Con el navegador: trece, correctos y completos. Google los veía; los asistentes de IA, ninguno. La empresa tenía su ficha de negocio, sus servicios y sus preguntas frecuentes descritos con precisión… en un sitio al que las IA no llegan.

Caso 2: el JSON roto que nadie veía. En nuestra propia web, dos páginas tenían el bloque de datos estructurados con el JSON mal formado —una coma fuera de sitio, un corchete cerrado una línea antes—. Cuando el JSON de un bloque es inválido, el buscador descarta el bloque entero: el texto sigue en el HTML, pero la ficha de empresa desaparece. Esto no se ve mirando la web. Solo se ve parseando el código, y llevaba meses así.

Caso 3: el contenido que no se puede citar. Cuatro artículos publicados como anclas dentro de una sola página (#article-1 a #article-4). Sin URL propia. Una IA no puede recomendar una dirección que no existe: como mucho, puede enlazar la página que los contiene y hablar del conjunto. Cuatro piezas de criterio técnico reducidas a una.

Qué significa

Los tres casos son el mismo problema visto desde tres ángulos: lo que no está en el HTML servido no existe para una IA, y lo que no tiene URL propia no se puede citar.

Esto no es una técnica nueva de posicionamiento: es una condición previa. De poco sirve escribir el mejor artículo de tu sector si el rastreador recibe una página vacía, o si tu ficha de empresa depende de que alguien ejecute un script de terceros.

Cómo se hace bien

  • Los datos estructurados, en el HTML que sirve el servidor. No inyectados con JavaScript. Si tu sitio usa un framework, esto se resuelve generándolos en el servidor.
  • El contenido, en el HTML. El texto que quieres que citen tiene que estar en la respuesta del servidor, no cargarse después.
  • Cada pieza con URL propia. Un artículo, una dirección. Las anclas no se citan.
  • El JSON, validado. No basta con que el bloque exista: hay que comprobar que se puede leer. Un bloque roto es peor que ninguno, porque da la falsa sensación de estar hecho.
  • Autor, fecha y fuentes visibles. Los motores de respuesta priorizan contenido atribuible. Un texto sin autor ni fecha es un texto que nadie puede evaluar.

Cómo se verifica

Cinco comprobaciones, todas contra la web publicada y ninguna a ojo:

  • El HTML servido contiene los datos estructurados que esperas.
  • Todos los bloques JSON se parsean sin error.
  • Cada artículo tiene su propio canonical.
  • Los títulos no se pasan de 60 caracteres.
  • No hay contenido que dependa de JavaScript para existir.

Y una cosa que no hay que hacer

Marcar con datos estructurados cosas que no están en la página. Si el marcado describe servicios, precios o valoraciones que el visitante no puede ver, el buscador lo trata como engaño. La regla es simple: lo que marcas, tiene que estar.
